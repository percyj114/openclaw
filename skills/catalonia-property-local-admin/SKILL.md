# Catalonia Property Local Admin

- `{baseDir}/../legal-spain-common/common/references/answer-contract.md`
- `{baseDir}/../legal-spain-common/catalonia-property/references/corpus-index.md`

Method:

1. Identify:
   - municipality
   - land classification
   - protected-area status
   - current registered use
   - intended works or use
2. Keep planning, environmental, cadastre, and registry analysis separate.
3. If the answer depends on municipal planning or park-specific rules, say exactly which document must be checked.

For practical property questions:

- State what looks permitted.
- State what likely needs prior approval.
- State what is high-risk without written confirmation.
- State which authority should be checked first.

For registry versus cadastre mismatch:

- Treat them as evidence layers, not as substitutes for planning status.

For sanctions or enforcement:

- Distinguish between regularization, legalization, and defense posture.

Special traps:

- Assuming existing use is legal because it is longstanding
- Assuming cadastre status equals planning status
- Change of use on protected land
- Heritage or environmental overlap
- WWOOF or Workaway arrangements drifting into labor or safety exposure
