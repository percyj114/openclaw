# Research Memo Checklist

Use this when the user asks for a memo, landscape summary, or "what changed" note.

## Memo structure

1. Issue
2. Bottom-line answer
3. Facts assumed
4. Current rule set
5. Recent changes
6. What is still uncertain or coming next
7. Practical implications
8. Sources to verify

## Rules

- Lead with the result, not the background.
- Separate binding changes from policy announcements or press comments.
- If the law is local or municipal, say which municipality controls the outcome.
- If 2025 or 2026 changes matter, verify dates before stating them.
